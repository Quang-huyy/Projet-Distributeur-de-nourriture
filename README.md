# Automatic Pet Food Dispenser

An embedded systems project focused on designing and developing an automatic food dispenser for a pet. The goal is to make feeding more convenient when the owner is away at school or otherwise unavailable.

## Overview

The project combines electronic circuit design and embedded software development to build a pet food dispenser.

The project is organized into two main parts:

- **Hardware design:** Electronic circuit design using KiCad.
- **Embedded software:** Microcontroller programming in C++ for the Arduino Nano.

## Technologies

- **C++** — Embedded software development
- **Arduino Nano** — Microcontroller platform
- **Arduino IDE** — Firmware development and compilation
- **KiCad** — Electronic circuit design

### Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Quang-huyy/Projet-Distributeur-de-nourriture.git
   ```

2. Open the project source files in the Arduino IDE.

3. Select **Arduino Nano** as the target board and configure the appropriate processor and port settings for your hardware.

4. Compile the firmware and upload it to the microcontroller.

5. Inspect the electronic design files using KiCad.

*Note: The exact wiring, component configuration, and operating procedure depend on the hardware design and firmware implementation.*
